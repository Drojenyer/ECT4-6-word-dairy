# 英语四六级词汇学习平台

基于 Electron 的桌面端四六级词汇学习工具。免安装、可便携携带，拷贝文件夹就能在任意 Windows 电脑上使用。

当前版本 **v1.0.0**

## 功能

### 学习

- **三种学习模式**：看词选义、看义选词、词卡浏览
- **断点续做**：每答一题即保存进度，关闭软件再打开自动从上次的位置继续
- **音标展示**：单词旁显示音标，共 5774 个词条有音标数据，词表里查不到的词不显示
- **每日词量**：10 / 20 / 30 / 50 / 100 可选
- **排除已掌握**：已标记掌握的词汇不再出现在日常学习中

### 高频词默写（见中写英）

- 标记为高频的词汇改用默写考察：给出释义与音标，手写英文单词
- **首字母默认给出**，点「提示字母」每次再多露一个字母，至少留一个字母自己写
- 借助提示才拼对的词**不算真正掌握** —— 不标记已掌握、也不推进复习阶段，很快会再考一次
- 日常学习每局只挑约 **1/3** 的题目改默写（按真题频次从高到低挑），避免一局全在打字；错词复习里高频错词则全部默写
- 可在「设置 → 学习设置」中关闭此模式

### 错题本

- **6 种排列方式**：最近加入 / 最早加入 / 字母 A-Z / 按级别 / 错误最多 / 优先复习
- **2 种显示模式**：条状详细（含例句与复习信息）、网格简略（一屏扫视更多单词）
- **错词专项测试**：只出错题本里的词，答对推进记忆曲线
- 排列方式与显示模式都会记住，重开软件保持不变

### 艾宾浩斯记忆曲线

- 复习间隔 **0 / 1 / 2 / 4 / 7 / 15 / 30 天**，答对逐级推进，答错退回第一阶段
- 走完全部阶段标记为「已掌握」
- 每条错词显示状态徽章：`今日复习` / `N 天后复习` / `已掌握`
- 首页在有待复习错词时弹出提醒卡，一键开始复习

### 外观自定义

- **主题色**：经典蓝、青碧、松绿、罗兰紫、玫红、暖橙、素雅灰
- **背景色**：浅灰、纯白、暖米、护眼绿、暗夜（深色模式）
- **界面圆角**：紧凑 / 标准 / 圆润
- **卡片密度**：紧凑 / 标准 / 宽松
- **5 套预设样式**：一键套用配色组合

深色模式下所有状态色（正确/错误/警告）都会切换为半透明底 + 亮色前景，不会出现浅色块压在深色界面上的问题。

### 其他

- 每日学习提醒通知（可设时段）、系统托盘常驻、开机自启动
- 学习统计：连续打卡、累计天数、测验次数、正确率、掌握词数、错题数

## 快速开始

### 方式一：直接使用（免安装便携版）

1. 解压 `英语四六级词汇学习平台_便携版.zip`
2. 双击 `英语四六级词汇学习平台.exe`

无需安装、无需配置、无需联网。拷到 U 盘或另一台电脑直接可用。

### 方式二：开发运行

```bash
npm install
npm start          # 启动应用
npm run dev        # 启动并打开开发者工具
```

### 打包便携版

```bash
npm run pack-portable            # 输出到 dist/
node build-portable.js E:\目标目录  # 输出到指定目录
```

打包脚本直接使用 `node_modules/electron/dist` 里已解压的 Electron 运行时组装，全程只做文件复制，无需联网，也不需要代码签名工具链。

## 数据说明

### 学习数据存放位置

| 运行方式 | 数据文件位置 |
|----------|--------------|
| 打包后的 exe | `<程序目录>\user-data\data.json` |
| 开发模式 | `%USERPROFILE%\.cet_vocab\data.json` |

打包版把数据放在程序目录下，因此**拷贝整个文件夹就能带着学习进度走**。若该位置不可写（例如装在 `Program Files`），会自动回退到用户目录，保证进度不会写不进去。

首次以便携模式运行时，若程序目录下还没有数据，会自动从用户目录迁移旧数据（保留原文件作为备份）。

### 写入安全

数据写入采用「先写临时文件再原子替换」，并对「读取 → 修改 → 写回」串行化，避免多个请求并发写坏 JSON。加载时若发现文件损坏，会先备份为 `.corrupt-*` 再回退到空数据，不会静默覆盖原始内容。

### 词汇数据来源

- 四六级词库：按考试大纲顺序排列的词表
- 高频词表：考研 + 四级 + 六级真题累加句频降序总榜（来源：`english-exam.lazynote.cn`），词频数据用于判断是否走默写模式、以及默写题目的挑选顺序
- 音标词典：四六级通用词典数据，提取其中的单词与音标

## 技术栈

- **Electron 27** — 桌面运行时
- **Express 4** — 内置本地 HTTP 服务（前端与后端同源，避免跨域）
- **原生 HTML / CSS / JavaScript** — 无前端框架，样式全部基于 CSS 变量实现主题化
