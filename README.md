# 英语四六级词汇学习平台

离线可用的四六级单词学习工具，支持 Windows 桌面端与 Android 手机端，免登录、无需联网。

## 下载

前往 [Releases](https://github.com/Drojenyer/ECT4-6-word-dairy/releases/latest) 下载对应平台的安装包：

| 平台 | 文件 |
|------|------|
| Windows | `ECT4-6-Word-Dairy-PC-v1.1.zip` |
| Android | `ECT4-6-Word-Dairy-Android-v1.1.apk` |

## Windows 端

1. 解压下载的 zip 压缩包
2. 双击 `启动学习平台.bat`，或直接运行目录内的 `英语四六级词汇学习平台.exe`

免安装、无需配置、无需联网。学习进度保存在程序目录的 `user-data` 文件夹中，**把整个文件夹拷贝到 U 盘或另一台电脑，进度会一起带走**。

## Android 端

1. 把 apk 文件传到手机
2. 点击安装，若系统提示「未知来源」，按提示允许一次即可

学习数据保存在应用内部，卸载应用会一并清除。可在「设置」里开启每日学习提醒。

## 使用说明

### 开始学习

打开后首页选择一种学习模式：

- **看词选义** —— 给出英文单词，选出正确的中文释义
- **看义选词** —— 给出中文释义，选出正确的英文单词
- **词卡浏览** —— 逐张翻卡查看单词、音标与词组例句

可在「设置」里调整每日词量（10 / 20 / 30 / 50 / 100）以及是否跳过已掌握的词。

### 断点续做

每答一题都会自动保存，关闭软件后再打开，会从上次中断的位置继续。

### 高频词默写

被标记为高频的词会改成「看中文写英文」。默认给出首字母，点「提示字母」可以再多露一个字母。借助提示才拼对的词不算真正掌握，之后还会再考一次。

### 错题本

答错或点「我忘记了」的单词会自动进入错题本。支持 6 种排序方式、2 种显示密度，也可以只针对错词做专项测试。

### 复习提醒（艾宾浩斯记忆曲线）

错词按 0 / 1 / 2 / 4 / 7 / 15 / 30 天的间隔安排复习，答对往后推进一个阶段，答错退回第一阶段。首页在有到期错词时会弹出提醒卡，可一键开始复习。

### 外观设置

主题色、背景色（含深色模式）、界面圆角、卡片密度都可以调整，另外提供 5 套一键套用的预设样式。

## 常见问题

**提醒没有弹出来？**
先确认「设置 → 提醒」已开启，并且当前时间在设定的提醒时段内。另外程序刚启动的前 5 分钟、以及正在学习的过程中不会弹出提醒，同一个提醒 30 分钟内也不会重复弹出。

**换了电脑，怎么把学习进度带过去？**
Windows 端直接拷贝整个程序文件夹（进度在 `user-data` 里）；Android 端目前不支持导出，建议在同一台手机上一直使用。
